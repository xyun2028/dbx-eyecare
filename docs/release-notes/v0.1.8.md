# Eye眼 0.1.8

多平台版本。同一个插件现在能在 Windows、macOS 和 Linux 上跑，Intel、Apple Silicon
和 ARM64 都覆盖。

## 有什么

- **macOS**：CoreGraphics 的 `CGSetDisplayTransferByTable`，Intel Mac 和 Apple Silicon 用同一份实现
- **Linux**：X11 + RandR 的 `SetCrtcGamma`，走纯 Rust 的 x11rb，不依赖 libX11/libXrandr
- **ARM**：Windows ARM64、Linux arm64、Apple Silicon 都是同一套代码，没有 x64 专有假设
- **Wayland 说清楚**：Wayland 不给应用改 Gamma 表的权限，面板上直接写原因，
  不再让开关看起来生效、实际什么都没改
- **表长自适应**：X11 的 Gamma 表不一定是 256 个点，写之前按 crtc 的实际长度重采样
- **备份格式升级**：`original_ramp.txt` 从定长 CSV 换成带表长的 JSON，
  旧文件仍然能读，升级后不会把屏幕卡在上一版的偏色上

功能本身没变：色温 1000–6500K、七个预设、按时段自动切换、20-20-20 提醒、逐屏独立。

## 安装

这个包**未签名**，装之前要先在插件中心打开「允许安装未签名开发包」。

1. 下载对应平台的 `com.eyecare.dbx-0.1.8-<target>.dbxp`
2. 插件中心 → 从本地安装，选这个文件
3. 装好后工作台会出现「Eye眼」标签页

`<target>` 是 `windows-x64` / `darwin-x64` / `darwin-arm64` / `linux-x64` / `linux-arm64`。
本次只出了 `windows-x64`，其余平台需要在各自平台上打包后补进同一个 Release。

Windows 上实际跑过：枚举屏幕、写 Gamma 表、退出还原、备份往返，21 个单测通过。
macOS 和 Linux **只过了编译**（x64 和 arm64 两种架构都检查过），还没有在真机上跑过，
实际写入效果要等真机验证后再确认。

## 已知限制

- **Wayland 不支持**。XWayland 能连上，但改的是它自己那份假表，桌面本身不变。
  需要完整生效请登录 X11 会话。
- **macOS 开了原彩显示或 Night Shift 会叠加**，最终颜色不是插件单独算出来的那个。
- **HDR 状态只有 Windows 查得到**，macOS 上 `hdr` 字段返回 `null`，不会有提示。
- **亮度是软件层缩放**，不是调显示器背光。
- 独占全屏的程序不受影响，这是 Gamma 表被绕过的正常现象。
