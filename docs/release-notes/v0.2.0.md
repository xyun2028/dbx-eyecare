# Eye眼 0.2.0

一天里不再只有「白天一档、夜间一档」。现在是一条可以自己画的 24 小时曲线，
再配上自定义预设、日出日落、工作日与周末分开、以及一份用眼记录。

## 有什么

- **自定义预设**：把当前色温（或滤色）和亮度一起存下来，起个名字，以后一点就用。
  内置的七个还在，自定义的排在后面，鼠标移上去可以删。
- **24 小时曲线**：一天里放多个锚点，每个锚点定一个色温。锚点之间保持不变，
  离下一个锚点还剩设定的分钟数时才开始过渡——不会一整天都在缓慢变色，
  也不会到点「啪」一下突变。
- **日出日落**：填经纬度，按当地的太阳时间决定什么时候变暖。冬至和夏至不用手动改。
  计算在本地做，不联网、不申请定位权限，极昼极夜会退回固定时刻。
- **工作日 / 周末**：两条独立曲线。周末默认跟着工作日，改一次就单独出去，
  也可以一键恢复跟随。
- **休息提醒落到屏幕上**：20-20-20 到点时，屏幕会在休息的二十秒里变暖变暗，
  不打开面板也能察觉。不想被这样提醒可以在面板上关掉，只留横幅。
- **用眼记录**：今天亮了多久、休息了几次、当前连续看了多久、这一天最长连续多久，
  保留最近 30 天。电脑睡眠的那段不会算进去。

老配置不用手动迁移：读到只有 `dayKelvin` / `nightKelvin` 的配置时，
会自动补成两个锚点，原来的设置原样保留。

## 界面

主面板从三栏变成两行：

```
控制   | 预设 | 20-20-20
曲线（跨两栏） | 用眼
```

曲线上每个圆点都可以拖：左右改时刻，上下改色温。拖动过程只改预览，
松手才写进配置，不会一路发请求。选中某个点后，下方的输入框可以精确改时间与色温。

## 安装

这个包**未签名**，装之前要先在插件中心打开「允许安装未签名开发包」。

1. 下载对应平台的 `com.eyecare.dbx-0.2.0-<target>.dbxp`
2. 插件中心 → 从本地安装，选这个文件
3. 装好后工作台会出现「Eye眼」标签页

`<target>` 是 `windows-x64` / `darwin-x64` / `darwin-arm64` / `linux-x64` / `linux-arm64`。

## 验证到哪一步

- 44 个单元测试通过：色温换算、Gamma 表重采样、备份往返、日出日落（深圳夏至/冬至、
  北京冬至、极昼极夜）、曲线插值与跨零点、周末切换、用眼累加与睡眠断档
- 界面在浏览器里用演示后端跑过：拖动锚点（07:00/5500K → 09:35/3850K）、
  切换日出日落（曲线变成四个点、锚点锁定、显示当天日出日落时刻）、
  周末独立设置与恢复跟随、保存自定义预设
- 深浅两套主题都截图检查过，没有溢出和重叠
- **没有在真实 DBX 宿主里加载过这一版**；宿主侧的事件形状以实际表现为准

## 已知限制

- 日出日落要自己填经纬度。插件没有定位权限，也不联网。
- 用眼记录只在插件跑着、并且护眼开关打开时累加。
- 曲线上锚点的**数量是固定的**：新装是五个，从老版本升级上来是两个。
  这一版只能拖位置和改色温，还不能增删锚点。
- **macOS 和 Linux 仍然只过了编译**，没有在真机上跑过。
- 亮度是软件层缩放，不是调显示器背光。
- 独占全屏的程序不受影响，这是 Gamma 表被绕过的正常现象。
- HDR 开启时 Gamma 表会被系统绕过，只有 Windows 能查到 HDR 状态。
