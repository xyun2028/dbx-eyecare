# Eye眼 0.1.6

修复界面不跟随 DBX 主题的问题。

## 改了什么

- **跟随 DBX 的浅色/深色主题**：之前宿主给的 `theme` 是对象 `{ appearance, tokens }`，
  插件按字符串判断，永远不成立，最后退回到操作系统设置——DBX 用浅色、Windows 用深色时，
  面板会一直是深色。
- **切主题即时生效**：监听宿主的 `dbx-plugin-env` 事件，不用重开标签页。
- **配色贴近宿主**：卡片、边框、次要文字改用 DBX 的 `--color-*` 设计变量，
  拿不到时退回自带配色。

功能与界面结构没有变化，只是颜色来源换了。

## 安装

这个包**未签名**，装之前要先在插件中心打开「允许安装未签名开发包」。

1. 下载 `com.eyecare.dbx-0.1.6-windows-x64.dbxp`
2. 插件中心 → 从本地安装，选这个文件
3. 已经装着 0.1.5 的，直接覆盖安装即可

## 已知限制

- **只支持 Windows**。macOS 和 Linux 的接口不同，还没实现。
- **开了 HDR 的屏幕不生效**，界面上会提示。
- **独占全屏的游戏和视频不受影响**，这是 Gamma 表被绕过的正常现象。
- **亮度是软件层缩放**，不是调显示器背光，最低压到 10%。
- 不要和桌面版 [eyecare](https://github.com/xyun2028/eyecare) 同时开——
  两个程序会各自定时重写 Gamma 表，互相覆盖，表现是颜色来回跳。
