# Eye眼 0.1.5

在 DBX 里调屏幕色温的插件。改的是显示器的 Gamma 查找表，不是在屏幕上盖一层半透明色板——
画面不会发灰，几乎不占显卡，多块屏幕还能各调各的。

首个公开版本。

## 有什么

- **色温**：1000–6500K 连续调节，配亮度调节
- **预设**：原色 / 轻度 / 办公 / 夜间 / 睡前 / 豆沙绿 / 纸质暖黄
- **按时间自动**：白天和夜间两档色温，到点前后线性过渡，不是突然跳变
- **20-20-20 提醒**：每工作 20 分钟提醒抬头看远处 20 秒，倒计时就在面板上
- **逐屏独立**：可以只调其中一块显示器，其余保持原样
- **HDR 提示**：屏幕开了 HDR 时明确告诉你那块不生效，不至于被当成插件坏了

## 安装

这个包**未签名**，装之前要先在插件中心打开「允许安装未签名开发包」。

1. 下载 `com.eyecare.dbx-0.1.5-windows-x64.dbxp`
2. 插件中心 → 从本地安装，选这个文件
3. 装好后工作台会出现「Eye眼」标签页

正式上架后可以直接从插件中心安装，不用再开这个开关。

## 已知限制

- **只支持 Windows**。macOS 和 Linux 的接口不同，还没实现。
- **开了 HDR 的屏幕不生效**。Windows 在 HDR 下会绕过 Gamma 表，写进去也没有变化，
  界面上会提示。
- **独占全屏的游戏和视频不受影响**，这是 Gamma 表被绕过的正常现象。
- **亮度是软件层缩放**，不是调显示器背光，最低压到 10%。
- 不要和桌面版 [eyecare](https://github.com/xyun2028/eyecare) 同时开——
  两个程序会各自定时重写 Gamma 表，互相覆盖，表现是颜色来回跳。

## 关于签名
